# 🌱 AgriCalc

A Python-based Agriculture Data Analyzer built with Streamlit.

## Features
- Upload CSV datasets
- Automatic seed germination calculation
- Summary metrics
- Bar Chart
- Line Chart
- Scatter Plot
- Pie Chart
- Clean agriculture-themed interface

## Required CSV columns

```text
Treatment
Seeds_Sown
Seeds_Germinated
Yield_g
```

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deployment

Upload the project to GitHub and deploy `app.py` through Streamlit Community Cloud.

The sample datasets contain simulated values for educational and demonstration purposes.
