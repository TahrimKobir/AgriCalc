# 🌱 AgriCalc

A polished Python-based Agriculture Data Analyzer built with Streamlit.

### Technologies
- Python
- Streamlit
- Pandas
- Matplotlib

### Features
- CSV upload
- Automatic germination calculation
- Summary metrics
- Treatment comparison
- Interactive charts
- Responsive Streamlit interface

### Run
```bash
pip install -r requirements.txt
streamlit run app.py
```

The included demo data are simulated for educational/portfolio demonstration.
